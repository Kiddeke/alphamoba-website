AlphaMOBA

A lane-and-jungle MOBA for Windows.

AlphaMOBA is set in a haunted forest. It has 67 champions, a 3v3 map, a 5v5 map and a 1v1 practice lane. The game is still in development, and you can download the current build now.

Install the game

The launcher installs the game and keeps it updated. Updates only download the files that changed.

Download the launcher

Windows 10 or 11 · 64-bit · a small exe, then about 7 GB for the game

  1. Run WychwoodLauncher.exe. The launcher isn't signed yet, so Windows may show a warning. Choose More info, then Run anyway. You only have to do this once.
  2. Wait for the install. The launcher moves itself to %LOCALAPPDATA%\Wychwood, adds shortcuts to your desktop and Start menu, and downloads the game.
  3. Play. Use the shortcut from now on. The launcher updates the game, and itself, each time you start it.

About the game

What kind of game it is

It plays like other MOBAs: lanes, towers, a jungle, a shop and a nexus to destroy. The maps are haunted forests, and each champion is built around one main mechanic.

One mechanic per champion

Gall has no mana and spends health instead. Nil has no resource and no ability power, and can't be revealed. Morvane's candle burns down in combat and relights outside it. Mei counts every hit she takes, and at twelve she turns into the Haunting.

Jungle and objectives

The jungle camps hold wolves, shades and stone sentinels, and the sentinels give buffs. Two altars on the riverbanks give a damage or a speed blessing. On the Hushwood, the Kraken spawns in the middle at seven minutes and gives 250 gold to the team that kills it.

Balanced on data

The game's simulation runs separately from the graphics, so thousands of bot matches can be played quickly. Balance changes are based on their results, and every formula has a test. The results are on the stats page.

The big map

The Witchwood

The Wardens' Lodge against the Coven. Three lanes and a full jungle, bases in the corners, one river across the middle with a pit at each end of it.

1v1

Learn the game

The Toll Road

One lane with minion waves, you against a bot. The first to destroy a tower wins. A good way to learn a champion.
